  "A crafted payload with a valid 4-byte OOXML/ZIP magic header (PK\x03\x04) but a
   corrupt body clears the magic-byte gate yet is not a parseable workbook. POI's
   XSSFWorkbook/WorkbookFactory then raises a runtime NotOfficeXmlFileException
   (POIXMLException), which the parsers' `catch (IOException)` did not catch, so the
   raw POI exception surfaced to the caller instead of failing closed ...
   Wrap the five SEC-D34 excel import parsers (bank deposit, NHIS claim, caregiver
   NHIS, NHIS visit schedule, RFID transmission) so any parse-time IOException or
   RuntimeException is converted to a BusinessRuleException(엑셀 파일을 읽을 수 없습니다.),
   while re-throwing the parsers' own BusinessRuleException validation messages unchanged."
