어르신 정보보호

네트워크 및 하드웨어 보안, 데이터 보안을 나열한 테이블
네트워크 및 하드웨어 보안 데이터 보안
서버(하드웨어)는 안전한 IDC센터에서 관리합니다.
:역삼 KT 영동 IDC 센터
  • 데이터의 안정적 유지를 위해 트윈서버운영
NETWork Traffic 분석을 통해 서버 관리 및 네트워크관리를
일별,주별,월별로 분석합니다.
  • 시설별 별도의 데이터베이스를 관리합니다
  • SSL 을 적용하여 보안을 강화하였습니다.
시스템 사용자보안수칙을 나열한 테이블
시스템 사용자보안수칙
  • 윈도우즈 보안 패치 자동 업데이트 설정하기
  • 바이러스 백신 및 스파이웨어 제거 프로그램 설치하기
  • 윈도우즈 로그인 패스워드 설정하기
  • 패스워드는 8자리 이상의 영문과 숫자로 만들고 2개월마다 변경하기
  • 신뢰할 수 있는 웹사이트에서 제공하는 프로그램만 설치하기
  • 인터넷에서 다운로드 받은 파일은 바이러스 검사하기
  • 출처가 불분명한 메일은 바로 삭제하기
  • 메신저 사용 중 수신된 파일은 바이러스 검사하기
  • 인터넷상에서 개인 및 금융정보를 알려주지 않기
  • 중요문서 파일은 암호를 설정하고 백업 생활화하기
  • 아이디와 비밀번호는 절대 타인에게 알려주지 않기
  • 컴퓨터는 사용 후 반드시 로그아웃하기
  • 프로그램별 사용자권한을 각각 부여하기

시스템 보안

시스템보안 구분, 세부사항을 나열한 테이블
구분 세부사항
사용자 인증 서버 OS에서 제공하는 보안기능 사용
  • 사용자 ID/PASSWORD관리, 파일시스템 관리
  • 사용자 실시간 모니터링
데이터베이스
  • 관리자, 사용자 권한 및 테이블별 접근 권한의 분리
  • ID/Password 에 의한 접근관리
어플리케이션
  • Sign-On 인증(조직자, 책임자 ID 및 패스워드)
  • 프로그램별 사용권한 체크
보안정책 보안의 관리 책임 명시
  • 시스템의 보안관리 범위 설정
  • 보안관리 책임자, 보안담당자의 선정 및 역할 정의
  • 관리자 유저는 1명으로 제한
